# example

A placeholder panel for tests and for trying lupin out: three made-up cell
types (`CT1`, `CT2`, `CT3`), two made-up marker genes each (`GENE1` ...
`GENE6`), and made-up Cell Ontology ids in its sidecar (`CL:9000001`,
`CL:9000002`; `CT3` is left unmapped on purpose).

- **Source**: written by hand for lupin; describes no real tissue or data.
